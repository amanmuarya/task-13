# Even or Odd Number Checker

This project checks whether a given number is even or odd using JavaScript.

##    Files included:
- index.html - The main HTML structure

- style.css - The styling for the project
- script.js - The JavaScript logic for checking even or odd numbers

- README.md - Project information.

##    to run:
1. Open index.html in your web browser
2. Check the console to see the results
